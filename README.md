# ぶっぱなせ！ちび軍団 / ぶっちび

未公開v15・全10代表戦のレビュー候補です。全100面版ではありません。

左右ドラッグで移動し、自動射撃します。成長ゲートは命中した弾を止め、10命中で数字が1増えます（上限+999）。正数は兵士の足元が通ると増援、負数は金色リングの指揮中心で判定します。縦に続く+1板は1発で壊れ、増援を1人得ます。後続の配置には空き列があり、ゲートを育てるか敵を撃つか選べます。

ボスの接近停止を修正しています。HPや兵力上限を増減する調整、時間無敵は追加していません。突進型は元の突進動作を維持します。

HTTPサーバーでindex.htmlを配信してください。ビルド/APIキーは不要です。保存キーと旧セーブ移行を維持しています。既存の中断データは兵力・進行・配置を保って再開し、新ルールを適用します。新しい配置は新規開始・再試行から適用されます。
