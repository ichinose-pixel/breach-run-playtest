# ぶっぱなせ！ちび軍団 / ぶっちび

未公開 v17 最終候補。10代表帯の試遊版であり、全100面版・TestFlight提出版ではありません。

左右ドラッグで移動し自動射撃します。成長ゲートは弾を止め、10命中ごとに+1、最大+999。正の値は兵士の足元が通ると増援になり、負の値は指揮リングの中心で接触判定します。縦の+1板は一発で壊れ、1人ずつ増援になります。後続のゲート列には敵を撃てる空き列があります。

v16ではボス弾の固定損失上限を外し、実際に着弾範囲に入った表示兵数と軍団の論理人数に合わせて被害を計算します。砲撃の楕円予告と判定範囲は一致します。ボス予告をHUDで優先し、障害帯の案内は接近時に表示します。一般兵の接近速度はv15のままです。攻撃間隔は序盤・中盤・終盤で段階化し、予告時間は短縮していません。新規開始の05・07・10ボスのみHPを20%増加。時間無敵・HP下限・強制攻撃回数はありません。

射撃、板の命中と破断、増援、警告、装甲破断、撃破、クリアの音と通常戦／ボス戦の曲を独自の合成音で再設計しています。警告優先、BGMと射撃音の抑制、最大48発音を実装。素材購入や外部音源はありません。音の好みと実機スピーカーの評価はレビュー待ちです。

HTTPサーバーでindex.htmlを配信してください。ビルド・APIキーは不要。既存セーブID、所持合金、進行、途中状態、残HPは保持します。新しい敵HPは新規開始・再挑戦から適用されます。
