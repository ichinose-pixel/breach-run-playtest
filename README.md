# Breach Run / ブリーチラン

左右にドラッグして狙い、仲間を増やして突破する全10ステージの3Dシューティングです。射撃は自動です。

`index.html` が入口です。HTTPサーバーでこのフォルダーを配信してください。GitHub Pagesの `/breach-run-playtest/` 配下でも動作する相対パス構成です。ビルドや外部APIキーは不要です。

進行はブラウザに保存されます。中断後はタイトルの「中断した作戦へ」から再開できます。「新規開始」はステージ1を始め、獲得済みの記録は保持します。音はタイトルで切り替えます。

3D用保存キーは `breach-run-amplify-prototype-v1` です。旧2D版の保存データには触れません。

素材とライブラリの出典は `THIRD_PARTY_NOTICES.txt`、Three.jsのMIT許諾文は `vendor/LICENSE` に記載しています。

増援ゲート、連続+1パネル、救出箱で実際の兵士と銃口を増やします。後半は狙撃兵の直線予告、砲台・戦車の着弾円を見て移動します。砲台・戦車の形状と音は本作のオリジナルです。動きを減らすOS設定を尊重します。

このフォルダーはGitHub Pagesで配信する試遊版です。Windows Chromeでの検証はiPhone/Safari・TestFlightでの実機検証の代わりにはなりません。
